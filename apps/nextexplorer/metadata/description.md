# NextExplorer

## English

NextExplorer is a modern, self-hosted web file explorer with a polished interface and secure access control. It supports resumable uploads, a built-in file editor, and thumbnail previews for browsing your local or network storage from a single web UI.

**Key features:**
- Clean, responsive file browser UI
- Secure user authentication and access control
- Built-in file editor and thumbnail previews
- Docker-native deployment, easy to self-host

**Source:** https://github.com/nxzai/NextExplorer
**Website:** https://explorer.nxz.ai

## Français

NextExplorer est un explorateur de fichiers web moderne et auto-hébergé, avec une interface soignée et un contrôle d'accès sécurisé. Il permet de parcourir vos stockages locaux ou réseau depuis une interface unique, avec éditeur de fichiers intégré et aperçus de miniatures.

**Fonctionnalités clés :**
- Interface de navigation claire et réactive
- Authentification et contrôle d'accès sécurisés
- Éditeur de fichiers intégré et aperçus de miniatures
- Déploiement natif Docker, facile à auto-héberger
